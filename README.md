# taobao-beauty-analysis
# 淘宝双十一美妆产品数据分析

## 📖 项目简介
本项目基于2022年淘宝双十一的美妆产品交易数据，分析了品牌竞争格局、价格与销量的关系以及评论转化率等核心问题。

## 🔍 分析内容
*   **市场格局**：识别了“规模驱动型”与“价值驱动型”等不同品牌竞争策略。
*   **价格与销量**：发现价格弹性存在品类异质性，并揭示了精华品类的“倒U型”价格-销量关系。
*   **评论与销量**：通过“评论转化率”指标，分析了不同品类用户评论意愿的差异。

## 📊 数据与代码
*   **数据来源**：Heywhale（和鲸）社区公开数据集。
*   **分析工具**：Python (Pandas, Matplotlib, Seaborn, Scipy)。

## 🚀 如何运行
1.  克隆本仓库到本地。
2.  安装依赖库：`pip install -r requirements.txt`（如果你创建了这个文件）。
3.  运行 Jupyter Notebook 或 Python 脚本。
